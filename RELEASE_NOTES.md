**Makkah Tower Home** — a custom home screen for Android TV / Google TV with prayer times built in.

Install in this order with the Downloader app: **SalahTimes.apk**, **Weather.apk**, **MakkahTowerHome.apk**.
Open Makkah Tower Home, follow the 3-step setup (city, prayer times, football teams), then switch on its
"Home button" helper in Settings → Accessibility so the remote's Home button opens it.
