## Makkah Tower Home — custom home screen for Android TV / Google TV

**Already installed? You don't need to do anything** — keep using it as it is.

### New here? Install in 3 steps
1. On the TV, install **Downloader** (by AFTVnews) from the Play Store, and allow it to install apps
   (Settings → Apps → Security & restrictions → Unknown sources → Downloader).
2. In Downloader, type the code **`8076512`** and select **Go**. This page opens.
3. Under **Assets** below, install the three apps **in this order**:
   1. **SalahTimes.apk** — prayer times, salah alerts, Qur'an player
   2. **Weather.apk** — weather
   3. **MakkahTowerHome.apk** — the home screen

### Then set it up
- Open **Makkah Tower Home**: choose your city, your prayer-time calculation (or your mosque's MasjidBoardLive
  board) and your football teams.
- **Settings → Accessibility → Home button → On**, so the remote's Home button opens it.
- **Settings → Apps → Special app access → Display over other apps → Salah Times → On**, for the prayer alert.

**Works on:** Google TV / Android TV 8.0 or newer (TCL, Sony, Hisense Google TV, Philips, Xiaomi, Chromecast with
Google TV, Google TV Streamer, Nvidia Shield). **Not on:** Fire TV, Hisense VIDAA, LG webOS, Samsung Tizen, Roku.

**To go back to the original home screen:** Settings → Accessibility → Home button → Off (and uninstall the apps
if you like).

Full guide with screenshots and troubleshooting: see the [README](https://github.com/Kyzasoze/makkah-tower-home#readme).
